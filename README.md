# AeroTech Projects — GitHub Pages website

Website pages: Home (`index.html`), About Us (`about.html`), Projects (`projects.html`), Blog & Research (`research.html`), Contact Us (`contact.html`).

## Publish
1. Upload all files in this folder to the root of your GitHub repository.
2. Commit the upload.
3. Open repository **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the published URL to appear.

## GA4
The Google tag is included on every page using Measurement ID `G-X9ZP9NK8TL`. After publishing, visit the live site and check GA4 **Reports → Realtime**. Events may take a few minutes to appear.

The contact form opens the visitor's default email app; it does not store form submissions.
